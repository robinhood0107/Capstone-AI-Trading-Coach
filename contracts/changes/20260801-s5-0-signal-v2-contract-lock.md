# S5.0 Signal v2 closed-union 계약 잠금

상태: `CONTRACT_LOCKED_RUNTIME_NOT_PUBLISHED`
관련 Issue: #76

## KR: 변경 이유

기존 Signal v1은 required HMM success shape 때문에 producer 실패와 모델의 정상 `HOLD` 예측을
구분할 수 없다. Signal v1/OpenAPI bytes는 그대로 유지하고, component마다
`AVAILABLE | ABSTAIN`인 별도 v2 계약을 잠근다. 이 계약은 조회 endpoint, artifact ingest,
RiskDecision 또는 주문 연결을 게시하지 않는다.

## EN: Rationale

Signal v1 cannot honestly distinguish unavailable required model evidence from a normal neutral
`HOLD` prediction. Keep Signal v1 and the current OpenAPI byte-identical while locking a separate
`AVAILABLE | ABSTAIN` v2 component union. This contract does not publish an endpoint or wire
artifact ingest, RiskDecision, or orders.

## exact union과 권한 / Exact union and authority

- `AVAILABLE`만 `asOf`, `signal`, `confidence`와 optional `predictedReturn`을 가질 수 있다.
- `AVAILABLE + HOLD`는 정상 neutral prediction이다.
- `ABSTAIN`은 producer/workspace/reason만 요구하며 prediction, confidence, asOf와 HMM state를
  만들 수 없다.
- stale, producer failure, artifact drift, missing evidence는 typed ABSTAIN이다.
- required component 하나라도 ABSTAIN이면 composite도
  `ABSTAIN/REQUIRED_COMPONENT_UNAVAILABLE`이다.
- cross-market, analyst, news/cause, RAG, LLM, RiskDecision, order authority field는 closed
  schema가 모두 거부한다.
- 교차시장 dataset/model sample weight, feature 또는 reader call은 0이고 첫 합류 세션은 S6.6이다.

```text
SIGNAL_V1_SCHEMA_UNCHANGED=true
CURRENT_OPENAPI_UNCHANGED=true
SIGNAL_V2_CONTRACT=LOCKED
SIGNAL_V2_ACTIVE_ENDPOINT=NO_GO
RISK_DECISION_WIRING=NO_GO
ORDER_WIRING=NO_GO
EXTERNAL_CALLS=0
```

generator catalog는 기존 bytes의 SHA-256을 고정한다.

- Signal v1 schema: `ae6b2285d1df7ce608778cd59c332332e8c44ce38a861d23d57dc8f0f9b912c2`
- Signal v1 fixture: `691cbb7b7f58ae3dbf411e3ff41d173cfdaf927ab3d6af973812dcdea3d9ae35`
- current OpenAPI: `94414736f6a1c17b95eafffd53a07a5d33d7a66705890c53dcc971eb5ded3f89`
