# S6.6/S6.7 strict-PIT capability retirement

## Decision

S6.6 event-study/policy replay/threshold freeze와 이를 소비하는 S6.7 P1 WARN_ONLY
materializer/reader/overlay는 현행 authority에서 퇴역한다. 무료 historical API 응답은
값을 제공했지만 과거 각 행의 실제 공개·수신 시각을 증명하지 못했으므로 현재 시각이나
공개 일정으로 `availableAt`을 소급하지 않는다.

S6.1~S6.5와 S4.8 offline 계약·scorer·sanitized evidence storage는 유지한다. S4.8의
Decision, Signal, RiskDecision, order authority는 계속 `NONE`이다.

## Versioning

- `s6-contract-lock.v1`과 기존 schema/catalog/generated bytes는 historical-only로 보존한다.
- `s6-contract-lock.v2`가 현재 S6 authority다.
- runtime catalog는 기존 exact-14 `s2-2-system-rule-catalog.v1`이다.
- `s2-2-system-rule-catalog.v2/v3`과 S6.6/S6.7 네 계약은 재현용 historical-only다.
- applied V78은 수정하지 않고 V79에서 runtime function capability를 폐쇄한다.

## Sanitized feasibility receipt

KIS 10회, KRX 1회, ECOS 1회, 공공데이터 2회로 총 14 physical call을 사용했다.
retry, 비용, live account, order call은 모두 0이다. raw provider body/header와 credential은
저장하거나 이 record에 포함하지 않았다. 이후 구현·검증의 runtime provider call은 0이다.
