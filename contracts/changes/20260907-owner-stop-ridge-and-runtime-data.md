# 개인 중지, Ridge 예측과 운용 데이터 정합성

사용자가 승인한 통합 수정이다. 전역 Kill Switch 정지·해제는 모두 ADMIN 전용으로 제한하고, 본인만 제어하는 `/api/v2/risk/kill-switch` GET/POST를 추가한다. root OpenAPI는 exact-76에서 exact-78로 전환하며 기존 root는 `p1-owner-ridge.previous.openapi.json`으로 보존한다.

V133은 별도 개인 상태·capability·멱등 전이·무효화·감사 기록을 추가하고, Decision·주문·자동운용에 개인/전역 OR 검증을 적용한다. 전역 capability는 발급 단계와 DB 사용 단계 모두 ADMIN을 요구한다.

V134는 기존 Team B exact-10과 일일 v1을 보존하면서 Ridge 계수·전처리·입력 해시·학습 종료일·1/5/20일 추정치를 동반 저장한다. 일일 v2는 v1과 Ridge를 원자 저장한다. 1일 수익률은 고정 50:50으로 결합하며 정렬·판단 hash에 구성값과 모델 버전을 결속한다. 가격 갭과 기존 왕복 비용 뒤 기대수익이 없으면 신규 매수를 하지 않는다.

규칙 baseline의 `signal`과 Ridge의 추정 수익률은 독립된 값이다. 기존 `predictedReturn`은
Ridge 1일 값에 대응하고 `returnForecasts`는 1/5/20번째 XKRX 거래일의 누적 단순수익률을
담는다. 종목·기간별 `StandardScaler + Ridge(alpha=1.0)`은 정답이 완성된 행만 학습한다.
LSTM은 현재 1일만 지원한다. 같은 batch의 기준일·대상일이 일치하는 두 1일 값만 평균하며
결측·stale·비정상 시 단독 모델로 대체하지 않는다. 실제 계산된 0과 미산출 상태를 구분한다.

자동운용은 `규칙 BUY AND LSTM != SELL`을 유지하고 결합 수익률로 후보를 정렬한다.
`예상 종가 / 현재 매수 지정가 - 1 - 35/10000`이 0 이하인 신규 매수는 제외한다.
`EQUAL_WEIGHT_50_50`·두 구성값·모델 식별은 판단 기록에 결속하고, 청산·수량·위험 한도는
기존 엔진의 권한을 유지한다. UI는 예측/실현 수익률과 고정 50:50 결합을 구분해 표시한다.

V135는 역사 정책/포지션을 덮어쓰지 않고 이전 저장 정책에 근거한 effective reader와 복원 receipt를 제공한다. 이후 v1 정책 writer도 이미 설정된 청산 기준을 보존한다. 운용 집계와 legacy 판정은 선택된 owner/account로 한정한다. 적용 정책·저장 정책·복원 출처 버전·다음 준비 시각을 구분한다.

RAG의 표시 경로는 인용 메타데이터가 잘못돼도 생성된 설명을 보존한다. 복구 불가능한 인용 연결은 MODEL_KNOWLEDGE/출처 대조 미완료로 표시하고, 기존 strict 검증은 MCP 검증 경계에 유지한다. 민감정보·크기·JSON 검증은 설명 복구 후에도 다시 수행한다.

실시간 시세·계좌·UI와 LSTM 다기간 예측, 모델 성능 비교는 [후속 TODO](../../docs/자동운용_후속_TODO.md)다. 실제 외부 호출·장중 체결 성공을 코드/fixture 검증만으로 주장하지 않는다.

V136은 LLM 설정 URL CHECK의 PostgreSQL 반복 범위 `{3,256}` 오류를 길이 검사와 문자 검사로 분리한다. 허용 URL 범위를 넓히지 않는다.

V137은 운용 실행에 생성 시점 account snapshot을 추가한다. 과거 계좌는 체결 lineage와 포지션이 일치할 때만 복원하고, 현재 운용 화면은 선택 계좌의 KIS 실행만 표시한다. 재생 기록과 계좌 미확인 이력은 삭제하지 않는다.
