# V200 운영자 AI 한도 초기 행 생성 순서

V200을 제한된 `flyway` 로그인으로 처음 적용하면, RLS를 강제한 뒤 기본 한도 행을
삽입하는 구 순서가 `42501`로 실패했다. 미출시 V200은 운영 상태 DB에 적용된 적이
없어 초기 행 삽입을 RLS 활성화 앞으로 옮긴다. 제품 설정·기존 사용자 데이터나
비용 정책값은 바꾸지 않는다.

`BoundMockCredentialIntegrationTest`의 독립 PostgreSQL 컨테이너에서 전체
Flyway 체인을 제한된 `flyway` 로그인으로 다시 적용하고 통과를 확인했다. 이미
V200을 적용한 외부 DB가 발견되면 체크섬을 덮어쓰지 말고 그 DB의 이력을 별도
확인해야 한다.
