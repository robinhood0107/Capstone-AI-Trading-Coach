# MARS DEMO v2 독립 웹·Agent 경계

## 상태

`contracts/openapi/mars-demo-v2.openapi.json`이 v2.0.0의 HTTP 경계입니다. 이전 `/api/v1/demo/agent/ask` 및 Spring `mars-demo` profile은 새 DEMO 제품에서 사용하지 않습니다. 해당 anonymous controller와 FULL API의 DEMO 전용 public mode branch를 제거했고, FULL API는 이전 경로에 404를 반환합니다.

## 제품 경계

- DEMO는 `workspaces/mars-demo`의 독립 Next.js 앱이며, 공통 UI 이외에 자체 session/overlay/fixture/Vertex adapter만 사용합니다.
- FULL Spring API에는 DEMO controller나 방문자 session이 없습니다. FULL 웹은 기존 아이디·이메일 로그인, Google/Kakao 연결, KIS 주문 계약을 유지합니다.
- DEMO cookie는 무작위 8시간 세션이고 SQLite 키는 session ID의 SHA-256입니다. JWT, FULL users, PostgreSQL, Redis, actor secret과 공유하지 않습니다.
- Agent 질문은 DEMO 서버에서만 Vertex를 호출합니다. 브라우저에는 provider credential이 없습니다. actual usage·비용·실패 상태만 기록하고 질문·답변 본문은 저장하지 않습니다.
- `MARS_DEMO_AI_DAILY_HARD_CAP_USD`는 retired stack용 shared setting이며 v2는 읽지 않습니다. v2는 DEMO session/global call limit, concurrency, request rate, request byte/output token ceilings와 계산된 daily cost bound를 사용합니다.

## 배포 결과

DEMO는 Docker Hub 저장소 `pjjpjj111/mars-demo`의 독립 semver tag와 digest를 사용하며, compose는 `web` 한 이미지와 `mars-demo_state` 한 볼륨만 선언합니다. FULL 이미지는 `pjjpjj111/mars-full`에 남습니다. GitHub Actions는 candidate build/scan/SBOM, registry publish, 수동 NAS promotion, 운영 확인을 별개 상태로 둡니다. 이전 v1 DEMO tags는 나중에 검증과 NAS cutover, 참조 전환, rollback window가 끝난 뒤 승인된 정리 단계에서만 삭제할 수 있습니다.
