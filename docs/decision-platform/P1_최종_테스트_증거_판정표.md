설계상 기본이 off이고, 켜려면 credential과 승인이 따로 필요합니다. 현재 상태를 사실대로 적습니다.

| RAG 소스 등록·수집·청킹·BGE-M3 임베딩·hybrid 검색 | 동작 (로컬) |

| RAG 웹 검색 (SearXNG), 강한 LLM | off |
