# P1 최종 테스트·증거 판정표

`PASS`는 같은 candidate commit/tree와 digest-pinned asset에 결속된 현재 실행 증거만 뜻한다. 과거 merge,
live smoke, synthetic fixture 또는 단독 focused test는 해당 leaf의 회귀 근거일 뿐 최종 gate를 자동으로
통과시키지 않는다.

| gate | PASS 증거 | 현재 상태 | 차단 효과 |
|---|---|---|---|
| Intake/contract | 두 bundle manifest copy match, v1 freeze, v2 schema/negative tests, OpenAPI/schema/proto/Flyway | partial PASS | contract drift면 중단 |
| Python | clean env `uv --frozen` full suite | NOT_RUN | hard block |
| Kotlin | JDK 25 `ktlintCheck build`, full Testcontainers | NOT_RUN | hard block |
| Dashboard | `npm ci`, typecheck/lint/unit/contract/build/Playwright | BLOCKED_NO_LOCK_TESTS | UI capability partial |
| Return Engine | lock/unit/contract/golden/backtest/E2E와 real artifact manifest | BLOCKED | hard block |
| Seed | data-only export, split/archive hashes, 142/7,871/1024, clean restore/no-op | IMPLEMENTED_REVALIDATED_GIT_AND_FRESH_DB | final Compose 결속 전 hard gate 후보 |
| BGE/OCR | clean download resume/corruption, 1024 finite/L2, born-digital+scan E2E, CPU/Intel | PARTIAL_CPU_BOOT_BGE_EMBED_PASS | hard block |
| CUDA | 제공된 smoke를 사용자 실제 하드웨어에서 실행 | PENDING_USER_HARDWARE_VERIFICATION | non-blocking disclosure |
| Compose | Linux/WSL and Windows clean install, restart, account/RAG/backup/market-data flows | NOT_RUN | hard block |
| Provider read | exact one-shot content-free receipt, retry/account/balance/order 0 | REVALIDATION_REQUIRED | hard block |
| Security | secret/dependency/image scan, repository security closure | INCOMPLETE | hard block |
| Supply chain | SBOM/provenance/cosign, anonymous GHCR pull, archive exclusion | NOT_RUN | hard block |

최종 실행은 `deploy/p1/full-app-release-manifest.v2.schema.json`의 `FINAL` 검증을 마지막 독립 gate로 둔다.
모든 hard gate가 `PASS`가 아니면 `.github/workflows/p1-full-app-release.yml`은 tag 또는 GitHub Release를
만들 수 없다.
