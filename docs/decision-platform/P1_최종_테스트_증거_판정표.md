### provider가 꺼져 있는 기능

설계상 기본이 off이고, 켜려면 credential과 승인이 따로 필요합니다. 현재 상태를 사실대로 적습니다.

| 기능 | 상태 |
|---|---|
| RAG 소스 등록·수집·청킹·BGE-M3 임베딩·hybrid 검색 | 동작 (로컬) |
| RAG 생성형 답변 (Vertex Gemini) | off. `RAG_V2_VERTEX_ENABLED=false` |
| RAG 웹 검색 (SearXNG), Voyage 임베딩, 강한 LLM | off |
| 뉴스 거부권 실 Vertex transport | 미연결. 미설정이면 `ABSTAIN`으로 fail-closed |
| GDELT online | off. 검증 뒤 `PROVIDER_DISABLED` |
| LightGBM 신호 | 은퇴 (V74). composite는 항상 `ABSTAIN` |
| LSTM 추론 gRPC 서버 | 기동하나 번들 미설정이라 `FAILED_PRECONDITION` |
