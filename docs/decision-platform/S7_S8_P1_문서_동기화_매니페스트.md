# S7–S8/P1 문서 동기화 매니페스트

## EOF receipt

2026-08-22 최종 동기화 전후 `docs/`와 local-only reference tree를 `lstat` 의미로 분류했다. regular
Markdown 207개를 EOF까지 읽었고 총 228,277 lines, 12,703,863 bytes였다. symlink 1개는 따라가지
않고 skip했다. 루트 README는 별도로 234 lines, 11,035 bytes를 읽고 사용자 문서로 재작성했다.

로컬 전용 경로 목록과 그 내용은 이 public manifest에 기록하지 않는다. 로컬 전용 참고자료의 tracked
file은 0이어야 한다.

## 분류 규칙

각 Markdown은 아래 우선순위 규칙으로 정확히 하나의 상태를 갖는다.

1. `contracts/changes/**`, completed-session record, historical evidence/transcript/worktree copy는
   `PRESERVED_HISTORICAL`이다. 이번 동기화에서 rewrite하지 않는다.
2. 아래 current authority 목록은 `UPDATED_CURRENT`다.
3. 나머지 tracked Markdown은 `VERIFIED_UNAFFECTED`다. S7/S8/P1 current authority와 충돌하는지
   EOF audit하고 변경이 필요하지 않음을 확인했다.
4. local-only current plan/ADR/primer/handoff는 local manifest에서 `UPDATED_CURRENT`, 나머지 local
   reference는 `VERIFIED_UNAFFECTED` 또는 `PRESERVED_HISTORICAL`로 같은 우선순위로 분류한다.
