# S8 사용자 테스트 킷

이 폴더는 향후 인간대상 사용자 테스트를 위한 준비물이며 실제 참가자 수행 결과가 아니다.

구성:

- `operator-guide.md`: 모집 전 gate, 진행, 중단, 삭제 절차
- `consent-and-data-notice.md`: 동의, 최소수집, 접근 owner, 보존과 철회
- `questionnaire.v1.json`: boolean/선택형/bounded score만 허용하는 문항
- `evidence-manifest.v1.json`: 보고서 근거 7종 폴더의 허용 파일과 금지 데이터
- 응답 계약: `contracts/schemas/s8-user-test-response.v1.schema.json`

자유서술 응답, 이름, 이메일, 학번, 전화번호, 계좌번호, 투자성향, 주문 권한 정보는 받지 않는다.
실제 수집 전 학교 IRB의 심의 또는 면제 판단을 받아야 하며 연구자가 임의로 면제를 선언하지 않는다.

현재 상태:

```text
S8_4_KIT_READY_PARTICIPANT_RUN_NOT_EXECUTED
```
