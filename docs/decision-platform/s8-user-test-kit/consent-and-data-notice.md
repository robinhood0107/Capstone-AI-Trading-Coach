# 동의 및 데이터 안내문 v1

이 테스트는 투자 권한을 평가하거나 투자 조언을 제공하지 않고, 안전 경계의 이해 가능성을 개선하기
위한 교육 연구다. 참여는 자발적이며 중단 또는 철회에 불이익이 없다.

수집 항목은 opaque participant ID, 동의 버전/시각, 네 안전 과업의 boolean·선택형 답,
1~7 usability 점수, 1~5 confidence 점수, 최대 3개 개선 tag, withdrawal code hash뿐이다.
이름, 연락처, 학번, 계좌, 주문, 실제 보유자산, 개인 투자성향, 자유서술은 수집하지 않는다.

접근자는 승인된 연구책임자와 최소 분석자에 한정한다. 원응답은 승인된 연구계획의 보존기간까지만
암호화 저장하고, 종료 또는 유효한 철회 요청 시 삭제한다. 보고서에는 집계 count와 비식별 결과만
포함한다.

동의 UI는 아래 두 선택만 제공한다.

- `AGREE`: 안내를 이해하고 자발적으로 참여
- `DECLINE`: 참여하지 않으며 응답 저장 0

실제 수집 전 학교 IRB의 사전 판단이 필요하다. 관련 기준은
[생명윤리법 제15·16조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029630559),
[개인정보보호법 제16조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029335671),
[개인정보보호위원회 가명정보 처리 가이드라인](https://www.pipc.go.kr/np/cop/bbs/selectBoardArticle.do?bbsId=BS289&mCode=D040070000&nttId=10433)을 따른다.
