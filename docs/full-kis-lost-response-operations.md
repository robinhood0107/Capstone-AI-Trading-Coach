# FULL KIS 주문 응답 유실 시 확인

KIS 주문 POST의 응답이 끊겨도 같은 주문을 다시 제출하지 않는다. 같은 세션의 KIS 주문 내역에서 제출 전에는 없던 주문이 종목, 방향, 수량, 지정가, 주문구분, 시각으로 유일하게 확인될 때만 원주문 참조를 복구해 체결 대사를 이어 간다. 주문 내역이 불완전하거나 여러 건이 일치하면 새 주문을 보류하고 사람에게 근거 확인을 요청한다.

운영 복구 시에는 KIS 주문·체결·잔고를 각각 확인하고, 로컬 주문과 자동운용 보유의 수량·계좌 범위·digest를 한 트랜잭션에서 대사한다. 재무장은 미해결 주문이 없고 관측 digest가 일치한 뒤에만 진행한다. 서비스 health만으로 체결·대사나 용량 검증을 완료한 것으로 보지 않는다.
