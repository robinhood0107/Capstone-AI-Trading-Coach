## 이 실행에서 드러난 것

- **매수가능 조회는 `symbol`과 `price`가 필수 query인데 OpenAPI에 선언돼 있지 않다.** 생성된
  client를 그대로 쓰면 언제나 400이다. 선언을 고치려면 동결된 exact-56/33 전이 사슬을 다시
  승인해야 해서 지금은 사실만 기록하고 Team A 요청서에 옮겼다.
- **대사는 ADMIN 전용이다.** 소유자에게는 403이 맞다.

## 아직 이 증거가 의미하지 않는 것
