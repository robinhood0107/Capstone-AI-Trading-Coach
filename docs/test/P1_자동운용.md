# 자동운용 v1·v2 표면과 경계

`tests/e2e/automation_v1_e2e.py` · 증거 `artifacts/decision-platform/e2e/automation-v1.json`

| 기능 | 방식 | 결과 |
|---|---|---|
| v1 status·runs와 v2 status | stack | PASS — v1 `DISARMED`, v2 blocker 3종 노출 |
| 지어낸 결속으로는 arm이 열리지 않는다 | stack | PASS — 404, 상태 불변 |
| 낡은 버전은 거절된다 | stack | PASS — 409, 버전 불변 |

관측된 blocker: `REAL_TEAM_B_POINTER_INACTIVE`, `RELEASE_BINDING_UNCLEAN`, `CERTIFICATION_INVALID`.
셋 다 외부 대기이거나 거래시간 의존이며, blocker가 있는 동안 arm이 닫히는 것이 설계다.

## 뉴스 거부권

종목 뉴스 코퍼스(`CorpusDocumentSource`)가 없어 근거가 항상 비어 있다. 그래서 자동운용 런타임의
기본 거부권 전송은 provider socket을 열기 전에 닫는다. 이 사실은 DB 관측이 아니라 그 클래스의
동작 자체가 증거다.

## 아직 이 증거가 의미하지 않는 것

- 실제 Team B 산출물이 아니다. 여기서 쓴 번들은 합성 golden이고 `evidence_mode`가 그 사실을 말한다.
- 실제 Team A UI가 아니다. 대시보드는 현재 tree의 화면이며 최종본이 아니다.
- 실계좌 거래가 아니다. KIS Live 호출은 영구 금지이고 이 기록 어디에도 그 경로가 없다.
- 시장이 열린 시간의 실체결이 아니다. 그 항목은 `P1_장시간_의존_항목.md`가 따로 다룬다.
