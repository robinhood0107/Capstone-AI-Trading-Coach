# 시연용 DB

`capstone-p1-demo` 스택에는 2026-08-18 ~ 2026-09-04 구간의 주문·체결, 판정 이력, 학습일지가
들어 있습니다.

**실제 데이터입니다.** 그 기간에 KIS 모의투자 계좌로 자동운용이 실제로 돌면서 남긴 포지션에서
그대로 만들어졌습니다. 종목·수량·체결가·손익은 어느 것도 지어내지 않았습니다.

다만 용도는 **시연입니다.** 화면이 비어 있으면 무엇을 보여주는 제품인지 설명하기 어려워서,
시연할 때만 이 기록을 얹은 스택을 따로 씁니다. 평소 쓰는 `capstone-p1` 스택에는 들어 있지
않습니다.

두 스택은 같은 이미지, 같은 코드, 같은 설정으로 돕니다. 차이는 이 기록이 있느냐 없느냐
하나뿐입니다.
